
# E-commerce Sample Data

This folder contains synthetic datasets used for the
Databricks Data Engineering portfolio.

Planned datasets:
- customers.csv
- products.csv
- orders.csv
- order_items.csv

The datasets will be used to practise data ingestion,
PySpark transformations, Delta Lake, data quality,
and Bronze/Silver/Gold architecture.

All sample data must be synthetic and must not contain
real customer information or credentials.
